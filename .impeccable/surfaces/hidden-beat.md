# Hidden beat extension
THESIS: Discovering small clues assembles a beat, then reveals an instrument the visitor can play.
OWN-WORLD: Inherit Graphite + Drafting; small monochrome symbols and a restrained mixer.
STORY: Four discoveries → quantized entrances → full beat → combined mute/solo and effects.
FIRST VIEWPORT: Compact personal index; one unobtrusive but accessible audio clue by the identity. No autoplay.
FORM: Existing-surface extension, code-led; seed: none (pinned). Desktop mixer uses four track strips; mobile uses two columns and scrollable effects with persistent transport controls.
FINISH: Local prototype; keyboard and mobile checks, audio-level evidence, state tests, and documented playback boundaries.
